# CodeAtlas

A Rust project for code analysis and exploration.

## Getting Started

### Prerequisites

- Rust (latest stable version)
- Cargo (comes with Rust)

### Building the Project

```bash
cargo build
```

### Running the Project

```bash
cargo run
```

### Running Tests

```bash
cargo test
```

### Development

This project uses:
- `cargo fmt` for code formatting
- `cargo clippy` for linting
- `rust-analyzer` for IDE support

### Project Structure

```
codeatlas/
├── src/
│   └── main.rs          # Main application entry point
├── tests/               # Integration tests (create as needed)
├── Cargo.toml          # Project configuration and dependencies
└── README.md           # This file
```

## Contributing

1. Ensure your code follows Rust conventions
2. Run `cargo fmt` before committing
3. Run `cargo clippy` to check for common mistakes
4. Add tests for new functionality
