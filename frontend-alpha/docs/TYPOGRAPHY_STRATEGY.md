# Uveddi Frontend Typography Strategy

## Brand Personality Analysis
**Core Attributes:** Technical Excellence, Trust, Innovation, Professional, Developer-focused

## Recommended Font Pairing Strategy

### Primary System (Recommended)
- **Headlines/Display**: **JetBrains Mono** - Technical, modern, perfect for developer tools
- **Body Text**: **Inter** (keep current) - Excellent readability, neutral personality
- **Code/Technical**: **SF Mono** (fallback to system monospace)

### Alternative System (High-end option)
- **Headlines/Display**: **Founders Grotesk** - Modern, distinctive, strong personality
- **Body Text**: **Inter** (keep current)
- **Code/Technical**: **Berkeley Mono** - Premium monospace with character

## Typography Scale
Based on Material Design principles, adapted for technical content:

### Desktop Scale
- **Display Large**: 64px (4rem) - Hero headlines
- **Display Medium**: 48px (3rem) - Section headlines
- **Display Small**: 36px (2.25rem) - Subsection headlines
- **Headline Large**: 32px (2rem) - Card titles
- **Headline Medium**: 24px (1.5rem) - Component titles
- **Headline Small**: 20px (1.25rem) - Small titles
- **Body Large**: 18px (1.125rem) - Lead paragraphs
- **Body Medium**: 16px (1rem) - Standard body text
- **Body Small**: 14px (0.875rem) - Secondary text
- **Caption**: 12px (0.75rem) - Labels, metadata

### Mobile Scale (Responsive adjustments)
- **Display Large**: 48px (3rem) - Reduced hero size
- **Display Medium**: 36px (2.25rem) 
- **Display Small**: 28px (1.75rem)
- **Headline Large**: 24px (1.5rem)
- **Headline Medium**: 20px (1.25rem)
- **Headline Small**: 18px (1.125rem)
- **Body Large**: 16px (1rem)
- **Body Medium**: 16px (1rem) - Increased for mobile readability
- **Body Small**: 14px (0.875rem)
- **Caption**: 12px (0.75rem)

## Line Height Standards
- **Headlines**: 1.1-1.2 (tighter for impact)
- **Body Text**: 1.5-1.6 (optimal readability)
- **Captions**: 1.4 (compact but readable)

## Font Weights
- **Regular**: 400 (body text)
- **Medium**: 500 (emphasized text)
- **Semi-bold**: 600 (subheadings)
- **Bold**: 700 (headlines)

## Implementation Priority
1. **Phase 1**: Implement JetBrains Mono for headlines (free from Google Fonts)
2. **Phase 2**: Optimize font loading and performance
3. **Phase 3**: Consider upgrade to premium fonts for uniqueness
