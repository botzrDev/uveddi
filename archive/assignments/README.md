# Uveddi Release Plan – Solo Developer Track

This directory now tracks the sequential launch phases for getting Uveddi ready for public release as a solo developer. Each phase has its own assignment file with scope, tasks, and verification steps. Work straight through the list; only start the next phase after verifying the current one.

|-------|-------|---------|--------|-----------------------|

| [A2 – Product Surface Freeze](./ASSIGNMENT-A2-PRODUCT-FREEZE.md) | Feature flag & CLI spec alignment | Week 1 | Not Started | Spec vs CLI parity check |
| [A3 – Hardening Sprint Prep & Execution](./ASSIGNMENT-A3-HARDENING.md) | Bug triage, refactors, performance tuning | Weeks 1-3 | Not Started | Test + benchmark reports |

## How to Use These Assignments

1. Open the assignment file for the current phase and review the scope, tasks, and acceptance criteria.
2. Work through the checklist, capturing links to artifacts in your tracker.
3. Complete the verification steps at the end of the assignment before marking it **Complete**.
4. Update the table above by editing the Status column when you finish each phase.

Maintaining clear verification evidence is essential because you will review your own work between phases.
