# Uveddi Glossary

## Core Concepts

### Architectural Anti-Pattern
A common solution to recurring problems that generates negative consequences.

### Cyclic Dependency
When two or more modules depend on each other directly or indirectly.

### God Object
A class/module that knows too much or does too much (violates Single Responsibility Principle).

### Architectural Drift
When implementation gradually diverges from intended architecture.

## Analysis Terms

### AST (Abstract Syntax Tree)
A tree representation of source code structure.

### Dependency Graph
Visualization of relationships between code modules.

### Code Smell
Surface indication of deeper problems in code.

### Criticality Level
Severity classification (Critical/Warning/Suggestion).

## Technical Terms

### WASM Plugin
WebAssembly module extending Uveddi's analysis capabilities.

### Vector Database
Database optimized for storing and querying vector embeddings.

### Semantic Search
Search based on meaning rather than exact text matches.

### Tokenization
Process of breaking code/text into meaningful units for analysis.

## AI Terms

### Context Window
The amount of text an AI model can process at once.

### Temperature
Parameter controlling randomness in AI responses.

### Few-Shot Learning
Providing examples to guide AI behavior.

### Embedding
Numerical representation of code/text meaning.
