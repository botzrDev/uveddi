# Code of Conduct

As contributors and maintainers of the UVEDDI Community Edition, we pledge to foster an open and welcoming environment. Please be respectful and considerate in all interactions.

- Be respectful of differing viewpoints and experiences.
- Gracefully accept constructive criticism.
- Focus on what is best for the community.

For more details, see the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
