========================================
ROOT CAUSES IDENTIFIED
========================================

1. **Regex Engine Limitations**
   - Issue: Security patterns using lookahead/lookbehind assertions
   - Impact: 12+ security detector tests failing
   - Regex library doesn't support advanced regex features
   - Example: (?!\\d) causes parse errors

2. **Database State Pollution**
   - Issue: Tests not properly cleaning up between runs
   - Impact: 3-5 database tests
   - Tables already exist from previous test runs
   - Need proper test isolation

3. **Import Path Refactoring**
   - Issue: Test files reference old module structures
   - Impact: Integration tests won't compile
   - Examples:
     * uveddi::database::crud::Database (doesn't exist)
     * uveddi::api:: modules (removed in CLI-only refactor)
     * WebSocket test modules (web features removed)

4. **Feature Flag Misalignment**
   - Issue: Tests written for features no longer in cli-standard
   - Impact: Multiple test categories
   - Web, TUI, and enterprise features removed but tests remain

5. **Cache Behavior Changes**
   - Issue: File watcher patterns and cache eviction logic changed
   - Impact: 12 cache-related tests
   - Assertions don't match current implementation
