# Support Channels

## Getting Help

### GitHub Issues
For bug reports and feature requests:
- [Open an Issue](https://github.com/botzrDev/uveddi/issues/new/choose)
- Follow the issue template
- Include reproduction steps and logs

### Community Support
For general questions and discussions:
- [GitHub Discussions](https://github.com/botzrDev/uveddi/discussions)
- [Discord Server](https://discord.gg/uveddi)
- [Stack Overflow](https://stackoverflow.com/questions/tagged/uveddi)

## Response Times

| Channel | Expected Response Time | Best For |
|---------|------------------------|----------|
| GitHub Issues | 2 business days | Bugs, feature requests |
| GitHub Discussions | 1 business day | How-to questions |
| Discord | Within hours | Quick help |
| Stack Overflow | Varies | Public Q&A |
