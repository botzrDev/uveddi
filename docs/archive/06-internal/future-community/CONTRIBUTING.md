# Contributing to UVEDDI

Thank you for your interest in contributing to the UVEDDI Community Edition! Please read our [Guidelines](./GUIDELINES.md) and [Code of Conduct](./CODE_OF_CONDUCT.md) before submitting issues or pull requests.

## How to Contribute

- Fork the repository and create your branch from `master`.
- Write clear, concise commit messages.
- Ensure your code passes all tests and lints.
- Submit a pull request with a detailed description.
